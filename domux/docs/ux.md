# UX/UI DOMUX

## Principios
- Claridad operativa primero.
- Jerarquía visual fuerte.
- Componentes reutilizables.
- Alto contraste y accesibilidad.
- Mobile-first.
- Estados vacíos y feedback inmediato.

## Dashboard por rol
- Portería: acciones rápidas, colas, eventos recientes, visibilidad de alertas.
- Administración: indicadores, pendientes, incidencias, comunicados y trazabilidad.
- Residente: accesos recientes, paquetes, comunicados y PQRS personales.
